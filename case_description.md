# Учебный кейс: Анализ эффективности доставки дронов в компании "Небесная Доставка"

## Описание кейса

Вы аналитик в компании "Небесная Доставка", которая доставляет товары с помощью дронов. Платформа собирает данные о маршрутах, погодных условиях, времени доставки, заряде батарей, типах грузов и успешности приземления для оптимизации логистики. За последний год компания провела масштабный сбор данных по всем доставкам, и теперь руководству нужен глубокий анализ, чтобы оптимизировать процессы, повысить успешность доставок и снизить издержки.

В вашем распоряжении находится датасет, содержащий информацию о 5000 доставок, совершенных дронами компании. Каждая запись включает данные о погоде, характеристиках груза, параметрах дрона, условиях доставки и результатах операции.

## Задания для анализа

1. **Анализ успешности доставок**: помогите аналитикам понять, какие факторы наиболее сильно влияют на успешность доставки. Какие условия чаще всего приводят к неудачам?

2. **Оптимизация маршрутов**: руководство хочет увидеть, как различные факторы (расстояние, погода, тип груза) влияют на продолжительность полета и точность приземления.

3. **Энергоэффективность**: изучите, как различные параметры (вес груза, погода, модель дрона) влияют на расход батареи дронов.

4. **Влияние внешних условий**: проанализируйте, как погодные условия и время года влияют на эффективность доставки.

5. **Роли оператора**: изучите, как опыт пилота влияет на результаты доставки и использование энергии дронов.

6. **Географические особенности**: выявите различия в эффективности доставки в зависимости от зоны и типа местности.

7. **Типы грузов**: определите, какие типы грузов требуют особого подхода и влияют на успешность доставки.

## Общие рекомендации по анализу и визуализации

### Агрегированные показатели для расчета:
- Средняя успешность доставки по различным группам (погодные условия, тип груза, модель дрона)
- Средняя точность приземления (в метрах) по разным условиям
- Средний расход батареи по различным сегментам
- Средняя продолжительность полета по маршрутам и условиям
- Доли успешных доставок в различных категориях
- Суммарное количество доставок по периодам времени

### Рекомендации по визуализациям:

1. **Влияние скорости ветра на успешность доставки**:
   - Диаграмма рассеяния или линейная диаграмма
   - По горизонтали: скорость ветра
   - По вертикали: доля успешных доставок
   - Сравнение по категориям (например, разные пороговые значения)

2. **Сезонные изменения успешности доставок**:
   - Линейная диаграмма
   - По горизонтали: дата/месяц
   - По вертикали: средняя успешность доставки
   - Отслеживание трендов по сезонам

3. **Влияние веса груза на расход батареи**:
   - Точечная диаграмма с линией тренда
   - По горизонтали: вес груза
   - По вертикали: процент расхода батареи
   - Группировка по моделям дронов

4. **Влияние опыта оператора на успешность**:
   - Линейная диаграмма
   - По горизонтали: опыт в годах
   - По вертикали: средняя успешность
   - Отображение эффекта насыщения

5. **Точность приземления в зависимости от температуры**:
   - Точечная диаграмма
   - По горизонтали: температура
   - По вертикали: точность приземления (в метрах)
   - Поиск оптимального диапазона

6. **Сравнение успешности по типам грузов**:
   - Столбчатая диаграмма
   - По горизонтали: тип груза
   - По вертикали: доля успешных доставок
   - Сравнение всех категорий

7. **Влияние трафика на продолжительность полета**:
   - Нормированная столбчатая диаграмма
   - По горизонтали: уровень трафика
   - По вертикали: средняя продолжительность полета
   - Сравнение уровней загруженности

8. **Эффективность моделей дронов в разных условиях**:
   - Группированная столбчатая диаграмма
   - По горизонтали: модель дрона
   - По вертикали: успешность или точность
   - Цветовая группировка по погодным условиям

9. **Распределение доставок по районам**:
   - Столбчатая диаграмма
   - По горизонтали: тип района доставки
   - По вертикали: средняя точность приземления
   - Сравнение город/пригород/сельская местность

10. **Временные тренды**:
    - Линейная диаграмма
    - По горизонтали: дата
    - По вертикали: различные показатели (успешность, точность, расход батареи)

## Фильтры и элементы управления (для дашборда)

При создании итогового обзора (дашборда или набора визуализаций) необходимо использовать элементы управления для интерактивного анализа данных.

### Полезные фильтры:
- Фильтры по погодным условиям (солнечно, облачно, дождь и т.д.)
- Фильтры по типу груза (стандартный, хрупкий, скоропортящийся и т.д.)
- Фильтры по модели дрона
- Фильтры по типу района доставки (городской, пригород, сельский)
- Фильтры по времени (диапазон дат, месяцы, сезоны)
- Фильтры по уровню трафика

### Элементы управления:
- Выбор интересующего типа груза для детального анализа
- Переключатель между разными показателями (успешность, точность, расход батареи)
- Выбор диапазона опыта пилотов для анализа
- Переключатель между разными моделями дронов

### Требования к студенту:
1. Добавить на итоговый дашборд не менее трех фильтров по важным измерениям (погода, тип груза, модель дрона).
2. Добавить как минимум один элемент управления, который позволяет менять условия анализа (например, выбирать интересующий сегмент или диапазон значений показателя), и показать, как это влияет на выводы.
3. Обеспечить возможность сравнения различных сегментов и условий через интерактивные элементы.
